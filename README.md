# Список дел: Express и база данных

Крылов Василий Анатольевич, логин Moodle `vasiliy_only1f`. [Приложение на Helios](https://se.ifmo.ru/~s507353/todo/) позволяет добавлять дела, изменять названия, отмечать выполнение и удалять записи. После входа интерфейс показывает автора из серверной конфигурации. Все дела хранятся в MongoDB, включая изменения независимого клиента.

Слои `domain`, `application`, `infrastructure` и `presentation` отделяют валидацию, сценарии, MongoDB и HTTP. Зависимости собираются в `src/index.mjs`; тесты подставляют другой репозиторий. Интерфейс использует обычные HTML, CSS и JavaScript.

Сервер задаёт UUID, автора, время создания и `done=false`. Название после trim содержит 1–200 Unicode code points; `runId`: 1–64 латинских буквы, цифры, дефисы или подчёркивания. Ошибочный JSON, типы, лишние поля, пустой PATCH, некорректный UUID и отсутствие `runId` возвращают 400. Неизвестное дело возвращает 404, ошибка MongoDB — 503; ошибки имеют JSON-формат.

Все `/api/` требуют Bearer-токен; без него возвращается 401. Исключение: пустой CORS preflight OPTIONS. Токен вводится пользователем и остаётся в памяти вкладки. Раздельные пользователи `todo_app` и `todo_reviewer` имеют CRUD только в `tasks`, без административных полномочий.

Выбраны MongoDB и Helios: отдельная оплата не требуется, совместимые бинарники и права коллекции проверены. PostgreSQL факультета доступен, но создание отдельных ролей запрещено. Таблица ниже различает доступность документации и реальное DB-подключение; платные услуги не приобретались.

## Запуск

Нужны Node.js 24, npm и Docker Compose. Команды выполняются из корня репозитория. Не запускайте вторую копию поверх работающего стенда и не перезаписывайте его конфигурацию. `db:stop` сохраняет volume; повторная инициализация не удаляет дела.

```bash
npm ci
npm run setup:local
npm run assets
npm run db:start
npm run db:init
npm start
```

Открыть [локальное приложение](http://127.0.0.1:30356/). Токен для ввода в локальный интерфейс:

```bash
npm run token --silent
```

```bash
npm run check
npm run test:deployment
npm run test:integration
npm audit
npm run db:stop
```

## Контракт

| Метод  | Путь                       | Успех                                           |
| ------ | -------------------------- | ----------------------------------------------- |
| GET    | `/login/`                  | 200, логин, `text/plain`, без токена            |
| GET    | `/api/author/`             | 200, `{login, fullName}`                        |
| POST   | `/api/tasks/`              | 201, дело; тело `{title, runId}`                |
| GET    | `/api/tasks/?runId=manual` | 200, массив, включая `[]`                       |
| GET    | `/api/tasks/:id/`          | 200, дело                                       |
| PATCH  | `/api/tasks/:id/`          | 200, дело; непустой набор `{title, done}`       |
| DELETE | `/api/tasks/:id/`          | 204, без тела                                   |
| GET    | `/healthz/`                | 200 после чтения MongoDB, иначе 503; без токена |

Ответы API с телом имеют `application/json`; маршруты требуют конечный `/`. POST/PATCH принимают JSON до 8 KiB без сжатия.

## Данные

| API             | MongoDB `node_todo_final.tasks` | Правило                   |
| --------------- | ------------------------------- | ------------------------- |
| `id`            | String, поле `id`, unique index | UUID в нижнем регистре    |
| `ownerLogin`    | String                          | Автор из конфигурации     |
| `title`         | String                          | 1–200 символов после trim |
| `done`          | Boolean                         | Изначально false          |
| `runId`         | String                          | `[A-Za-z0-9_-]{1,64}`     |
| `createdAt`     | BSON Date                       | В API UTC ISO 8601 с `Z`  |
| Не возвращается | `_id`: ObjectId                 | Внутренний ключ MongoDB   |

Схема, индексы и роли: [schema.mjs](src/infrastructure/schema.mjs).
